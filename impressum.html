About this site

This page is the club’s Walkathon Step Challenge web app (step logging, club totals, and leaderboard). It is hosted separately from the main club website.

  • Static app hosting: GitHub Pages
  • API & step storage: Cloudflare Worker and Cloudflare D1
  • Member login: Wild Apricot single sign-on (club membership platform)

Club-wide legal details (bank information, general website disclaimer) also appear on the main AIWCD Impressum.
